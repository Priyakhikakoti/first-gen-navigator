================================================================================
  SECTION 4 — HOW TO RUN
================================================================================

# Install dependencies (first time only)
  npm install

# Fetch live data from Anakin (NIRF, JoSAA, scholarships, college fees)
  npm run scrape

# Start the app
  npm run dev
  → Open: http://localhost:3001

# API endpoints
  GET  /api/health          → Server status
  GET  /api/profile         → Current student profile
  POST /api/profile         → Save student profile
  GET  /api/colleges        → Tiered college matches
  GET  /api/scholarships    → Eligibility-checked scholarships
  GET  /api/affordability   → Cost calculator
  GET  /api/alternatives    → Strategic pathway plans
  GET  /api/documents       → Document vault (list)
  POST /api/documents       → Save/verify a document
  GET  /api/deadlines       → Upcoming deadlines
  GET  /api/roadmap         → Admission roadmap steps
  GET  /api/scrape-status   → Last Anakin scrape timestamp
  POST /api/refresh         → Trigger re-scrape (manual)
